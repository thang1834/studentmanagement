# Tài liệu lưu trữ

Các file trong thư mục này là tài liệu thiết kế và hướng dẫn của giai đoạn đầu dự án, khi bot dự kiến chạy bằng Node.js trên máy chủ riêng với Google Sheets API qua service account. Bản chạy thật hiện nay dùng Google Apps Script, nên **các hướng dẫn cài đặt ở đây không còn đúng**.

Giữ lại để tham khảo:

- `PROJECT_PLAN.md`: mục tiêu, phạm vi và mô tả chi tiết 8 tab dữ liệu (phần này vẫn đúng với cấu trúc Sheet hiện tại).
- `README-nodejs-cu.md`, `DEPLOYMENT-nodejs-cu.md`, `USER_MANUAL-nodejs-cu.md`: tài liệu của phương án Node.js.
- `appscript-README-cu.md`: README cũ của thư mục `appscript/`, đã gộp vào README gốc và `docs/`.

Tài liệu hiện hành: [README](../../README.md), [Hướng dẫn cho admin](../huong-dan-admin.md), [Hướng dẫn cho giáo viên](../huong-dan-giao-vien.md), [Tài liệu phát triển](../phat-trien.md).
